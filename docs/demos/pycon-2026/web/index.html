Decisión de cambio · Transformers v5.20.2

¿Qué puede romper
este cambio?

Un pull request modifica GenerationMixin.generate. Esta demo convierte “preguntarle al LLM” en una decisión revisable: qué código mirar, qué pruebas ejecutar y qué todavía no sabemos.

Ver el valor ↓

Objetivo: decidir qué revisar antes de aprobar, sin fingir que el análisis estático conoce todo el comportamiento en ejecución.

01 / El valor

De una respuesta plausible
a una decisión auditable.

El valor no es “usar un LLM”. Es impedir que una afirmación convincente se convierta en una decisión de ingeniería sin evidencia verificable.

RESPUESTA NO VERIFICADA

“600+ clases podrían verse afectadas”

En una corrida local observada, el modelo produjo esta magnitud. La afirmación no estaba respaldada por el paquete determinista y no puede usarse para aprobar el cambio.

EVIDENCIA ACOTADA

8 candidatos, 1 caller y 8 referencias de pruebas

El AST entrega ubicaciones concretas para inspeccionar. Son candidatos trazables, no una promesa de cobertura completa.

SUPERFICIE REVISABLE

3.682 bytes en lugar de 816.502

El agente recibe metadatos citados un 99,55 % más pequeños que los archivos completos. Es una comparación de bytes, no de tokens ni comprensión.

LÍMITE EXPLÍCITO

El runtime sigue abierto

Despacho dinámico, registros, extensiones nativas y caminos de ejecución todavía requieren verificación adicional.

DECISIÓN

Antes de aprobar: revisar el caller, inspeccionar los 8 candidatos y ejecutar pruebas dirigidas. El impacto completo en tiempo de ejecución sigue sin demostrarse.

03 / El registro determinista

Primero, lo que
el informe sí dice.

Cargando informe local…
UNRESOLVED

El grafo no demuestra el impacto completo en tiempo de ejecución. El despacho dinámico, los registros y las extensiones nativas quedan fuera de esta evidencia.

Cómo leer la medición de contexto

El informe compara bytes de metadatos con los bytes completos de los archivos citados. No mide tokens ni equivalencia semántica: es una reducción de tamaño, no una medida de comprensión.
